3. 💾 LOCAL MOBILE STORAGE (100% On-Device Vault)

All user data is stored strictly in your local mobile storage inside the Android sandbox-isolated SQLite database (/data/data/jmd.shiv.mypassword/databases/).

Even if your phone has zero internet connection or is in Airplane Mode, your passwords, notes, and screenshots are fully accessible and manageable on your device.

4. 🛡️ MILITARY-GRADE ENCRYPTION SPECIFICATIONS

A. Master Password: Cryptographic Hashing with Salt

Your Master Password is NEVER saved in plain text. It is hashed using PBKDF2WithHmacSHA256 with 100,000 iterations and an isolated 32-byte cryptographic Salt. Progressive rate-limiting hardware lockouts block brute-force attempts.

B. Username Saved in Encrypted Format

Usernames, Login IDs, and Email addresses are NOT stored in plain text. Every username is encrypted with AES-256-GCM using hardware-backed keys before being committed to SQLite storage.

C. Password Saved in Encrypted Format

All saved account passwords are encrypted using AES-256-GCM (Galois/Counter Mode with 128-bit authentication integrity tags). Each encryption generates a fresh, unique 12-byte random IV so identical passwords never create identical ciphertext.

D. Image Screenshots Saved in Encrypted Format

When you attach a login page screenshot, the image is compressed and encrypted into an AES-256-GCM Encrypted BLOB inside the database. No unencrypted image file is left in your public phone gallery or file manager.

E. Android Keystore Hardware Isolation

Master encryption keys are generated and isolated inside the hardware-backed Android Keystore System (TEE / StrongBox). Keys cannot be extracted even with file-system inspection.
