# Secure Password Manager - रिमोट नेटवर्क कनेक्टिविटी एवं VPN सेटअप गाइड

यह गाइड समझाती है कि जब आपका Android Mobile और Computer अलग-अलग नेटवर्क (उदा. मोबाइल 4G/5G डेटा पर हो और कंप्यूटर ऑफिस या घर के इंटरनेट पर हो) पर हों, तो सुरक्षित रिमोट कनेक्शन (Remote Web Access) कैसे स्थापित करें।

---

## 1. समस्या और समाधान (The Challenge & Solution)

| स्थिति | समस्या | सुरक्षित समाधान |
|---|---|---|
| **Same Wi-Fi** | दोनों एक ही राउटर पर हैं (`192.168.1.x`) | लोकल IP द्वारा सीधा एक्सेस: `http://192.168.1.105:8443` |
| **Router Client Isolation / Guest Wi-Fi** | एक ही वाई-फाई होने पर भी राउटर डिवाइसेज को आपस में बात करने से रोकता है | VPN नेटवर्क (Tailscale / WireGuard) |
| **अलग-अलग नेटवर्क (Remote)** | मोबाइल 4G/5G पर, कंप्यूटर ऑफिस में | सुरक्षित प्राइवेट मेश VPN (`100.x.x.x`) |

> ⚠️ **महत्वपूर्ण सुरक्षा चेतावनी (No Public Port Forwarding):**  
> अपने होम या ऑफिस राउटर पर पोर्ट फॉरवर्डिंग (Port Forwarding) करके मोबाइल को सीधे पब्लिक इंटरनेट पर कभी एक्सपोज़ न करें। यह अत्यंत असुरक्षित हो सकता है। इसके बजाय केवल **Tailscale** या **WireGuard** प्राइवेट एन्क्रिप्टेड टनल का उपयोग करें।

---

## 2. Tailscale VPN द्वारा 2-मिनट में रिमोट सेटअप (अनुशंसित विधि)

Tailscale एक ज़ीरो-कॉन्फ़िगरेशन प्राइवेट वायरगार्ड-आधारित VPN है जो सुरक्षित P2P एंड-टू-एंड एन्क्रिप्टेड कनेक्शन बनाता है।

### चरण 1: Android Mobile पर सेटअप
1. Google Play Store से **Tailscale** ऐप इंस्टॉल करें।
2. अपने Google, Microsoft या Apple खाते से साइन इन करें।
3. VPN कनेक्ट करें।
4. आपको एक स्थायी प्राइवेट IP मिलेगा (उदा. `100.85.120.45`)।
5. अब **Secure Password Manager** खोलें और **Computer Web Access** में जाएं।
6. ऐप स्वचालित रूप से VPN IP डिटेक्ट करेगा और दिखाएगा:  
   `http://100.85.120.45:8443 (Tailscale/WireGuard सक्रिय)`

### चरण 2: Computer (Google Chrome) पर सेटअप
1. अपने कंप्यूटर पर [tailscale.com](https://tailscale.com) से Tailscale सॉफ्टवेयर इंस्टॉल करें।
2. उसी खाते से साइन इन करें जो मोबाइल में उपयोग किया था।
3. अब कंप्यूटर और मोबाइल दोनों एक ही सुरक्षित वर्चुअल प्राइवेट नेटवर्क में आ गए हैं।

### चरण 3: Chrome में एक्सेस
1. कंप्यूटर के Google Chrome में यह URL खोलें:  
   `http://100.85.120.45:8443`
2. मोबाइल स्क्रीन पर दिख रहा 6-अंकीय पेयरिंग कोड दर्ज करें।
3. मोबाइल पर "स्वीकार करें (Approve)" दबाएं।
4. आपका कंप्यूटर सुरक्षित रूप से जुड़ जाएगा और सभी पासवर्ड्स रियल-टाइम में सिंक होंगे!

---

## 3. WireGuard VPN द्वारा सेटअप (Self-Hosted विकल्प)

यदि आपके कार्यालय में अपना WireGuard VPN सर्वर है:
1. मोबाइल और कंप्यूटर दोनों में WireGuard क्लाइंट कनेक्ट करें।
2. मोबाइल को आवंटित आंतरिक IP (उदा. `10.8.0.5`) को Secure Password Manager ऐप स्वचालित रूप से पहचान लेगा।
3. Chrome में `http://10.8.0.5:8443` खोलें और पेयर करें।

---

## 4. फ्यूचर क्लाउड रिले आर्किटेक्चर (Future Cloud Relay Architecture)

भविष्य के संस्करण के लिए क्लाउड रिले (End-to-End Encrypted Relay) की रूपरेखा:

```
[ Android Mobile ] <──(E2EE WebSocket)──> [ Cloud Relay Server ] <──(E2EE WebSocket)──> [ Chrome Browser ]
 (SQLite Database)                         (Zero-Knowledge Pipe)                          (Decrypted in Memory)
```

1. **शून्य-डेटा स्टोरेज (Zero Knowledge Pipe):**  
   क्लाउड रिले सर्वर केवल एक एंड-टू-एंड एन्क्रिप्टेड मैसेज पाइप की तरह कार्य करेगा। डेटाबेस कभी भी क्लाउड सर्वर पर स्टोर नहीं होगा।
2. **डिवाइस ऑथेंटिकेशन:**  
   मोबाइल और कंप्यूटर दोनों एक पेयरिंग सीक्रेट के आधार पर NaCl / ChaCha20-Poly1305 सत्र कुंजियाँ डिराइव करेंगे।
3. **सत्र समाप्ति एवं सुरक्षा:**  
   यदि मोबाइल रिले कनेक्शन काट देता है तो क्लाउड के माध्यम से कोई भी अनुरोध प्रोसेस नहीं होगा।
