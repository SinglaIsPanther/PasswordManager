# Secure Password Manager (सुरक्षित पासवर्ड मैनेजर) 🔐

एक आधुनिक, अत्यधिक सुरक्षित, और पूर्णतः ऑफलाइन Android पासवर्ड मैनेजर एप्लिकेशन — जिसमें कंप्यूटर के Google Chrome ब्राउज़र से सुरक्षित रूप से एक्सेस और लाइव पेयरिंग की सुविधा उपलब्ध है।

---

## 🌟 मुख्य विशेषताएं (Key Features)

- **100% Native Android & Pure Java**: कोई Kotlin या Compose नहीं, शुद्ध Native Java और XML में निर्मित।
- **AES-256-GCM मिलिट्री-ग्रेड एन्क्रिप्शन**: पासवर्ड, यूज़रनेम, नोट्स और स्क्रीनशॉट सभी फोन की लोकल मेमोरी में हार्डवेयर-समर्थित Android Keystore से सुरक्षित रहते हैं।
- **डायनामिक वेब पोर्ट (Dynamic Port Generation)**: प्रत्येक सफल लॉगिन पर सुरक्षा के लिए सर्वर नया रैंडम पोर्ट (8000–9999) जनरेट करता है।
- **एंबेडेड वेब सर्वर (Chrome Browser Access)**: कंप्यूटर के क्रोम ब्राउज़र में मोबाइल का IP और डायनामिक पोर्ट डालकर बिना फोन हाथ में लिए पासवर्ड एक्सेस व कॉपी करें।
- **QR कोड व 6-अंकीय TOTP पेयरिंग**: कंप्यूटर से कनेक्ट करने के लिए वन-टाइम ऑथेंटिकेशन टोकन प्रणाली।
- **मास्टर पासवर्ड व फिंगरप्रिंट बायोमेट्रिक लॉगिन**: सुरक्षित और त्वरित बायोमेट्रिक अनलॉकिंग।
- **सुरक्षा प्रश्न (Security Question) रिकवरी**: पासवर्ड भूलने पर बिना डेटा खोए सुरक्षित रीसेट।
- **कस्टम पासवर्ड जनरेटर (4 से 15 अक्षर)**: जटिल और सुरक्षित पासवर्ड बनाने की त्वरित सुविधा।
- **शून्य बाहरी ट्रैकर / नो ऐड्स**: कोई थर्ड पार्टी SDK या इंटरनेट पर डेटा भेजने वाला ट्रैकर नहीं।

## 🛠️ टेक स्टैक (Tech Stack)

| घटक (Component) | तकनीक (Technology) |
|---|---|
| **प्लेटफ़ॉर्म** | Android (API Level 26+) |
| **प्रोग्रामिंग भाषा** | Java (100%) |
| **UI लेआउट** | Native XML |
| **डेटाबेस** | SQLite (SQLiteOpenHelper) |
| **वेब सर्वर** | NanoHTTPD Embedded HTTP & WebSocket |
| **एन्क्रिप्शन** | Android Keystore + AES-256-GCM |

## 🚀 इंस्टॉलेशन एवं रन (How to Run)

1. रिपॉजिटरी को क्लोन या डाउनलोड करें:
   ```bash
   git clone https://github.com/<your-username>/PasswordManager.git
   ```
2. **Android Studio** खोलें और इस प्रोजेक्ट फ़ोल्डर को `Open` करें।
3. Gradle Sync पूर्ण होने दें।
4. अपने Android डिवाइस या एमुलेटर पर `Run` (Shift + F10) दबाएं।
